## 🎯 Описание

Advanced Map War Thunder — это настольное приложение для Windows, которое подключается к локальному API War Thunder (порт 8111) и отображает игровые данные в удобном графическом интерфейсе. Приложение использует DirectX 11 и библиотеку ImGui для создания современного пользовательского интерфейса.

## ✨ Возможности

### 🗺️ Интерактивная карта
- **Отображение всех объектов**: самолеты, наземная техника, корабли, аэродромы, базы
- **Цветовая кодировка**: объекты отображаются с цветами, соответствующими их типу и принадлежности
- **Панорамирование и масштабирование**: плавное перемещение по карте с инерцией
- **Режим слежения**: автоматическое отслеживание позиции игрока (клавиша `F`)
- **Метки на карте**: возможность ставить метки кликом мыши
- **Выделение объектов**: выбор и отслеживание конкретных юнитов

### 💬 Чат игры
- Отображение сообщений чата в реальном времени
- Фильтрация по типу сообщений (команда, командир, враг)
- История сообщений с прокруткой

### 📊 Индикаторы полета
- Скорость (IAS/TAS)
- Высота
- Компас
- Число Маха
- G-метр
- Топливо
- Рычаг газа
- Шасси и закрылки

### 🛩️ Состояние самолета
- Высота (H, м)
- Истинная скорость (TAS, км/ч)
- Индикаторная скорость (IAS, км/ч)
- Число Маха (M)
- Угол атаки (AoA, град)
- Вертикальная скорость (Vy, м/с)
- Топливо (Mfuel, кг)
- Обороты двигателя (RPM)
- Мощность двигателя (hp)

### 🎮 Информация о миссии
- Статус миссии (running/fail)
- Список целей с их статусом
- Отметка о выполнении целей

### ⚙️ Дополнительные функции
- **Режим отладки**: детальная информация о работе приложения (клавиша `D`)
- **Сохранение настроек**: автоматическое сохранение позиции и размера окна
- **Многопоточность**: асинхронная загрузка данных без блокировки интерфейса
- **Circuit Breaker**: защита от перегрузки API при недоступности игры
- **Connection Pooling**: оптимизация HTTP-запросов
- **Многоязычность**: поддержка французского и русского языков интерфейса (автоопределение по системе)
- **Встроенные шрифты**: кастомный шрифт symbols_skyquake.ttf встроен в исполняемый файл

## 🔧 Принципы работы

### Архитектура приложения

Приложение построено на многоуровневой архитектуре с разделением ответственности:

1. **Слой получения данных (ApiFetcher)**
   - Асинхронная загрузка данных из War Thunder API
   - Отдельные потоки для каждого типа данных
   - Circuit Breaker для защиты от перегрузки
   - Connection pooling для оптимизации HTTP-запросов

2. **Слой парсинга (JsonParser)**
   - Асинхронный парсинг JSON данных
   - Работа на отдельном потоке/ядре процессора
   - Очередь задач для обработки данных

3. **Слой представления (UI)**
   - Отрисовка интерфейса через ImGui
   - DirectX 11 для рендеринга
   - Обработка пользовательского ввода

4. **Слой данных (Data Structures)**
   - Структуры для хранения игровых данных
   - Thread-safe доступ через мьютексы
   - Глобальные переменные для обмена данными между модулями

### Поток данных

```
War Thunder (localhost:8111)
    ↓
ApiFetcher (отдельные потоки для каждого endpoint)
    ↓
Callback функции (ParseGameChat, ParseHudMsg, etc.)
    ↓
JsonParser (асинхронный парсинг)
    ↓
Глобальные структуры данных (с мьютексами)
    ↓
UI (отрисовка в главном потоке)
```

### API Endpoints

Приложение использует следующие endpoints War Thunder API:

- `http://localhost:8111/gamechat` - сообщения чата
- `http://localhost:8111/hudmsg` - события HUD
- `http://localhost:8111/indicators` - индикаторы полета
- `http://localhost:8111/state` - состояние самолета
- `http://localhost:8111/mission.json` - информация о миссии
- `http://localhost:8111/map_info.json` - информация о карте
- `http://localhost:8111/map_obj.json` - объекты на карте
- `http://localhost:8111/map.img` - изображение карты

### Оптимизация производительности

1. **Многопоточность**
   - Главный поток: интерфейс и рендеринг (привязан ко второму ядру)
   - Потоки API: загрузка данных (привязаны к первому ядру)
   - Поток парсера: обработка JSON (отдельный поток)

2. **Connection Pooling**
   - Переиспользование HTTP-соединений
   - Уменьшение задержек при запросах

3. **Circuit Breaker**
   - Защита от перегрузки при недоступности API
   - Автоматическое восстановление после ошибок

4. **Интерполяция движения**
   - Предсказание позиций объектов при пропуске обновлений
   - Плавное отображение движения

### Безопасность потоков

Все глобальные структуры данных защищены мьютексами:
- `g_chatMutex` - для сообщений чата
- `g_eventMutex` - для событий
- `g_indicatorsMutex` - для индикаторов
- `g_stateMutex` - для состояния
- `g_missionMutex` - для миссии
- `g_mapInfoMutex` - для информации о карте
- `g_mapObjectsMutex` - для объектов карты
- `g_mapMarkersMutex` - для меток

## 📦 Требования

### Системные требования
- **ОС**: Windows 10/11 (64-bit)
- **Процессор**: Двухъядерный процессор или выше
- **Память**: 4 GB RAM (рекомендуется 8 GB)

## 🚀 Установка

### Предварительно скомпилированная версия

1. Скачайте последний релиз из раздела [Releases](https://github.com/skynet174/AdvancedMapWarthunder/releases)
2. Распакуйте архив
3. Запустите `WarThunderAdvanced.exe`

### Настройка War Thunder

Для работы приложения необходимо включить локальный API в War Thunder:

1. Откройте War Thunder
2. Перейдите в настройки игры
3. Включите опцию "Enable localhost API" или "Разрешить локальный API"
4. Убедитесь, что порт 8111 доступен

## 🔨 Сборка

### Клонирование репозитория

```bash
git clone https://github.com/skynet174/AdvancedMapWarthunder.git
cd AdvancedMapWarthunder
```

### Генерация проектных файлов

Используйте скрипт `generate.bat` для автоматической генерации проекта:

```bash
generate.bat
```

Или вручную используйте premake5:

```bash
# Из корня проекта
premake5.exe vs2022
```

Или если premake5 установлен глобально:

```bash
premake5 vs2022
```

**Примечание:** При компиляции шрифт `symbols_skyquake.ttf` автоматически встраивается в исполняемый файл через `font_resource.rc`. Подробнее о процессе встраивания можно узнать, запустив `generate_font.bat`.

Для очистки промежуточных файлов сборки используйте:

```bash
clear.bat
```

1. Откройте `WarThunderAdvanced.sln` в Visual Studio
2. Выберите конфигурацию `Main` (Release)
3. Нажмите `Build` → `Build Solution` (или `Ctrl+Shift+B`)

Скомпилированный файл будет находиться в `Bin/Main/WarThunderAdvanced.exe`

## 🎮 Использование

### Запуск приложения

1. Убедитесь, что War Thunder запущен и локальный API включен
2. Запустите `WarThunderAdvanced.exe`

#### Клавиатура

- **Правая кнопка мыши** - Выделение объектов

#### Интерфейс
- **Вкладка "Карта"** - Интерактивная карта с объектами
- **Вкладка "Чат"** - Сообщения чата игры
- **Вкладка "Индикаторы"** - Параметры полета
- **Вкладка "Состояние"** - Детальная информация о самолете
- **Вкладка "Миссия"** - Цели и статус миссии

Настройки автоматически сохраняются в файл `config.ini` в папке с исполняемым файлом:

## 🏗️ Архитектура

### Основные компоненты

#### 1. ApiFetcher (Source/ApiFetcher.h, Source/ApiFetcher.cpp)

Класс для асинхронной загрузки данных из War Thunder API.

**Основные функции:**
- `Start()` - Запуск потоков загрузки данных
- `Stop()` - Остановка потоков
- `SetChatCallback()` - Установка callback для чата
- `SetEventCallback()` - Установка callback для событий
- `SetIndicatorsCallback()` - Установка callback для индикаторов
- `SetStateCallback()` - Установка callback для состояния
- `SetMissionCallback()` - Установка callback для миссии
- `SetMapInfoCallback()` - Установка callback для информации о карте
- `SetMapObjectsCallback()` - Установка callback для объектов карты

**Особенности:**
- Отдельные потоки для каждого типа данных
- Circuit Breaker для защиты от перегрузки
- Connection pooling для оптимизации
- Привязка потоков к первому ядру процессора

#### 2. JsonParser (Source/JsonParser.h, Source/JsonParser.cpp)

Асинхронный парсер JSON данных.

**Основные функции:**
- `ParseAsync()` - Асинхронный парсинг JSON строки
- `ParseFileAsync()` - Асинхронный парсинг JSON из файла
- `Stop()` - Остановка парсера

**Особенности:**
- Очередь задач для парсинга
- Работа на отдельном потоке
- Callback-функции для обработки результатов

#### 3. UI (Source/UI.h, Source/UI.cpp)

Модуль пользовательского интерфейса.

**Основные функции:**
- `InitializeUI()` - Инициализация UI
- `RenderUI()` - Отрисовка интерфейса
- `ShutdownUI()` - Очистка ресурсов
- `SaveSettings()` - Сохранение настроек
- `LoadSettings()` - Загрузка настроек

**Функции парсинга:**
- `ParseGameChat()` - Парсинг чата
- `ParseHudMsg()` - Парсинг событий HUD
- `ParseIndicators()` - Парсинг индикаторов
- `ParseState()` - Парсинг состояния
- `ParseMission()` - Парсинг миссии
- `ParseMapInfo()` - Парсинг информации о карте
- `ParseMapObjects()` - Парсинг объектов карты

#### 4. Translator (Source/Translator.h, Source/Translator.cpp)

Система переводов интерфейса.

**Основные функции:**
- `Get(const std::string& key)` - Получение переведенной строки по ключу
- `SetLang(const std::string& lang)` - Установка языка интерфейса
- `TR()` - Глобальный доступ к экземпляру переводчика

**Особенности:**
- Автоопределение языка системы Windows
- Поддержка французского (fr) и русского (ru) языков
- Fallback на русский язык при отсутствии перевода
- Используется во всем интерфейсе через `TR().Get("key")`

#### 5. FontEmbedded (Source/FontEmbedded.h)

Система встраивания шрифтов в исполняемый файл.

**Основные функции:**
- `FontData::GetData()` - Получение указателя на данные шрифта из ресурсов Windows
- `FontData::GetSize()` - Получение размера данных шрифта
- `FontData::IsLoaded()` - Проверка успешной загрузки шрифта

**Особенности:**
- Загрузка шрифта `symbols_skyquake.ttf` из Windows ресурсов (RCDATA)
- Шрифт встраивается в exe через `font_resource.rc` во время компиляции
- Не требует внешних файлов шрифтов для работы приложения
- Используется ImGui для загрузки шрифта из памяти

#### 6. Main (Source/main.cpp)

Точка входа приложения.

**Основные функции:**
- Инициализация DirectX 11
- Инициализация ImGui
- Загрузка и встраивание шрифтов (включая symbols_skyquake.ttf из ресурсов через FontEmbedded)
- Создание окна
- Главный цикл рендеринга
- Обработка сообщений Windows

- Шрифт `symbols_skyquake.ttf` встроен в исполняемый файл, внешние файлы шрифтов не требуются
- Язык интерфейса определяется автоматически по настройкам системы Windows (французский или русский)

## 🐛 Известные проблемы

- При первом запуске может потребоваться несколько секунд для подключения к API
- Если игра не запущена, приложение будет показывать ошибки подключения (это нормально)
- Некоторые карты могут не иметь изображения (зависит от версии игры)
- **Проблема с захватом/выделением юнитов**: API War Thunder не предоставляет уникальные ID для объектов на карте (`map_obj.json`). Из-за этого точное выделение и отслеживание конкретных юнитов затруднено. Приложение использует координаты, тип объекта и цвет для идентификации, но это не всегда надежно, особенно когда объекты находятся близко друг к другу или быстро движутся. Выделение может работать некорректно при большом количестве объектов на карте.
